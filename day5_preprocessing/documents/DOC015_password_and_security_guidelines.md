# TechNova Solutions - Password and Security Guidelines

Document ID: DOC015

## Purpose

The Password and Security Guidelines describe basic practices employees should follow to protect company accounts, systems, and information.

## Password Creation

Employees should create strong passwords that are difficult for unauthorized people to guess.

Passwords should not contain easily predictable information such as a person's name, common words, or simple number sequences.

## Password Protection

Employees must keep their passwords confidential and should not share them with colleagues, friends, or family members.

Passwords should not be written in publicly visible locations.

## Multi-Factor Authentication

Employees should use approved multi-factor authentication methods when required by company systems.

Authentication requests should not be approved if the employee did not initiate the login.

## Account Security

Employees should lock their workstation or laptop when leaving it unattended.

Employees should report suspicious account activity or unexpected login notifications through the approved security channel.

## Phishing Awareness

Employees should be cautious when opening unexpected links or attachments in emails and messages.

Suspicious requests for passwords, financial information, or confidential company information should be reported rather than answered.

## Software and Updates

Employees should install security updates provided through approved company systems.

Employees should not disable required security controls without authorization.

## Reporting Security Concerns

Employees should report suspected security incidents as soon as possible.

Examples may include a lost company device, suspicious login activity, suspected phishing, or accidental disclosure of company information.

## Responsibilities

Employees are responsible for protecting their accounts and following applicable security requirements.

The IT and security teams are responsible for providing appropriate security controls, guidance, and support.

## Guideline Review

TechNova Solutions may update these guidelines as security practices, systems, or threats change.
